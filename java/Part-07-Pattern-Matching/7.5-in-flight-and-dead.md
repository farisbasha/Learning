> **What this is:** So you can **read release notes and blog posts without being misled**.
> This is a short page whose whole purpose is calibration.

## ⭐ How the preview mechanism works

Java ships unfinished features deliberately, behind a flag:

```bash
javac --release 25 --enable-preview Main.java
java --enable-preview Main
```

**The rules:**

| Rule | Consequence |
|---|---|
| Both flags required | Compile **and** run |
| Class files are version-locked | Code compiled with preview on Java 25 **will not run on Java 26**, even with the flag |
| Features can change | Between preview rounds, without deprecation |
| Features can **vanish** | With no migration path |

**Preview → the lifecycle:**

```
incubator (APIs)  or  preview (language)
        ↓  usually 2–3 rounds, one per release
     finalised                 or      withdrawn
```

> ⚠️ **Never use a preview feature in production code.** The class-file version lock alone
> means every JDK upgrade forces a recompile, and the feature may not be there.

Preview features are for **giving feedback**, which is the point — the JDK team uses these
rounds to find out what's wrong before committing forever.

## Currently previewing `Java 27`

Read these as "real, changing, don't rely on it":

| Feature | What it is |
|---|---|
| **Primitive types in patterns** | `case int i when i > 0`, `x instanceof byte b` — patterns over primitives, not just references |
| **Structured concurrency** | `StructuredTaskScope` — treating a group of concurrent subtasks as one unit (9.12) |
| **Lazy constants** | `StableValue` — deferred initialisation the JIT can still constant-fold |

**Primitive patterns** are the one that most affects Part 07. Today:

```java
switch (o) {
    case Integer i -> ...;      // boxed only
}
```

Previewing:

```java
switch (someInt) {
    case int i when i > 100 -> "large";
    case int i              -> "small";
}
if (x instanceof byte b) { ... }     // safe narrowing conversion, checked
```

It completes pattern matching by removing the reference-types-only restriction.

## Long-running incubator

**The Vector API** — SIMD operations (`a[i] + b[i]` done 8 lanes at a time on the CPU's
vector units).

```java
var a = FloatVector.fromArray(SPECIES, arrayA, i);
var b = FloatVector.fromArray(SPECIES, arrayB, i);
a.add(b).intoArray(result, i);
```

It has been **incubating since Java 16 (2021)** — nine rounds and counting. It's waiting
on **Valhalla** (value types, 3.5), because without them a `Vector` object can't be
represented efficiently enough to make the API worth finalising.

> A useful data point on timelines: "incubating" can mean half a decade.

## 💀 String templates — the cautionary tale

```java
// Java 21 preview — DOES NOT EXIST ANYMORE
String message = STR."Hello \{name}, you are \{age} years old";
```

| | |
|---|---|
| Previewed | Java 21 (Sept 2023) |
| Second preview | Java 22 |
| **Withdrawn** | **Java 23 (Sept 2024)** |
| Status | **Gone. Not coming back in that form.** |

**Why it was withdrawn:** the design coupled the template processor (`STR`) to a new
`StringTemplate` type in a way the team came to consider wrong — especially for the
security use cases (SQL, HTML) that motivated it. Rather than finalise something they'd
regret, they pulled it.

**Why this matters to you:** there are hundreds of blog posts, tutorials and
conference talks about Java string templates. **They describe a feature that does not
exist.** Java 25 still has no string interpolation — you use `String.format`,
`"...".formatted(...)`, or concatenation (1.3).

> **The lesson: don't build on previews.** This is the clearest recent example, and it's
> why 0.3 tells you to check dates on everything.

## ⭐ The four big projects

Every significant JVM change for the next decade comes from one of these. Knowing the
names makes release notes readable.

### Valhalla — value types `not yet`

**Goal:** value classes and specialised generics — `List<int>` with no boxing (3.5).

```java
value record Point(int x, int y) { }     // no identity, no header, inlined into arrays
```

**Status:** in development for **over a decade**. Some pieces have landed (compact object
headers, 8.4). Generic specialisation has not.
**Will change:** memory layout, collection performance, the cost of abstraction.

### Loom — virtual threads ✅ **done**

**Goal:** make blocking cheap so you can have millions of threads.

```java
Thread.startVirtualThread(() -> { ... });
Executors.newVirtualThreadPerTaskExecutor();
```

**Status:** **finalised in Java 21.** Structured concurrency and scoped values are the
remaining pieces, still previewing.
**Changed:** the entire concurrency story. Reactive/async frameworks became largely
unnecessary for I/O concurrency (9.11).

### Panama — native interop ✅ **mostly done**

**Goal:** replace JNI with something usable.

```java
// Foreign Function & Memory API — final in Java 22
try (var arena = Arena.ofConfined()) {
    MemorySegment seg = arena.allocate(1024);
    // call a C function, no JNI, no C glue code
}
```

**Status:** **FFM API final in Java 22.** The Vector API (also Panama) still incubating.
**Changed:** calling native libraries went from "write C glue" to "write Java" (11.9).

### Leyden — startup time 🚧 **in progress**

**Goal:** make the JVM start fast, for containers and serverless.

**Status:** shipping incrementally — AOT class loading and linking `Java 24`, AOT method
profiling `Java 25`, AOT caching that works with any collector `Java 26`.
**Will change:** JVM startup, which is the platform's weakest point against Go and Node
(8.10).

| Project | Theme | Status |
|---|---|---|
| **Valhalla** | Value types, flat memory | ⏳ A decade in, not yet |
| **Loom** | Virtual threads | ✅ Done (Java 21) |
| **Panama** | Native interop | ✅ FFM final (Java 22) |
| **Leyden** | Startup time | 🚧 Landing incrementally |

## ⚠️ Traps

| Trap | Reality |
|---|---|
| Using a preview feature in production | Class files won't run on the next JDK |
| Reading about string templates | **They were removed.** They don't exist |
| "Incubating" means "coming soon" | The Vector API has incubated since 2021 |
| `--enable-preview` at compile only | Needed at **runtime** too |
| Assuming a preview will be finalised as-is | It can change, or vanish |

## Recap

| Point | |
|---|---|
| Preview | `--enable-preview` at compile **and** run; class files version-locked |
| Previewing now | Primitive patterns, structured concurrency, lazy constants |
| Incubating | Vector API — since 2021, waiting on Valhalla |
| 💀 **String templates** | Previewed 21, **withdrawn 23**. The blog posts are wrong |
| Valhalla | Value types. Not yet |
| **Loom** | Virtual threads. **Done — Java 21** |
| Panama | Native interop. FFM final — Java 22 |
| Leyden | Startup. Landing incrementally |
