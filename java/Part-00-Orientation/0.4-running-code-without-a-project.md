# 0.4 — Running code without a project

> **What this is:** You should be able to run a Java idea in **ten seconds**, with no
> build tool and no IDE ceremony. This is the step that makes the rest of the course
> pleasant instead of painful.

---

## Coming from JS/Python/Dart

`node x.js`, `python x.py`, `dart run x.dart` — one command, no setup. Java's reputation
says you need Maven, an IDE and a folder structure. **That reputation is out of date.**

---

## The concepts

### Do it by hand, once

Do this exactly once, so you know what every tool later is automating.

```java
// Hello.java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello");
    }
}
```

```bash
javac Hello.java   # compile → produces Hello.class (bytecode)
java Hello         # run → note: no .class extension
```

Two steps: **compile**, then **run**. Everything else in Java tooling exists to hide
these two commands.

### Launching a single file directly `Java 11`

The compile step disappears:

```bash
java Hello.java    # compiles in memory and runs. No .class file.
```

`Java 22` extended this to multiple files — `java Main.java` will also pull in the other
`.java` files next to it.

### Compact source files `Java 25` — the modern way

No class. No `static`. No `String[] args`.

```java
// hello.java
void main() {
    IO.println("Hello");
}
```

```bash
java hello.java
```

That's it. That's a complete Java program in Java 25.

> **What the old ceremony actually meant** — you'll see this in every older example,
> so decode it once:
>
> ```java
> public static void main(String[] args)
> ```
> | Part | Meaning |
> |---|---|
> | `public` | The JVM (outside your class) must be able to call it |
> | `static` | Callable without creating an object first — there is no object yet |
> | `void` | Returns nothing |
> | `String[] args` | Command-line arguments |
>
> Every word was a real requirement. Java 25 just stopped requiring them.

### `IO.println` vs `System.out.println` `Java 25`

```java
IO.println("hi");           // Java 25 — available without imports
System.out.println("hi");   // works everywhere, what you'll see in all older code
```

`System.out` is a static field (`out`) on the `System` class, holding a `PrintStream`.
`IO.println` is just a friendlier wrapper. Use `IO.println` when learning; recognise
`System.out.println` because 100% of existing code uses it.

### JShell — your main tool for Parts 01–07

This is the one that matters. `jshell` is Java's REPL.

```bash
jshell
```

```java
jshell> int x = 5
x ==> 5

jshell> x * 2
$2 ==> 10

jshell> "hello".toUpperCase()
$3 ==> "HELLO"

jshell> var list = new java.util.ArrayList<String>()
list ==> []

jshell> list.add("a")
$5 ==> true

jshell> list
list ==> [a]
```

Useful commands inside JShell:

| Command | Does |
|---|---|
| `/vars` | List variables you've defined |
| `/methods` | List methods you've defined |
| `/list` | Show everything you've typed |
| `/edit` | Open an editor for a multi-line snippet |
| `/exit` | Quit |
| `/help` | Everything else |

> **Use JShell constantly while reading these notes.** Every code block in Parts 01–07
> can be pasted into it. Don't read Java — run it.

### What an IDE is doing for you

IntelliJ / VS Code + Java extension are running `javac` on every keystroke, maintaining
the classpath, and reading the resulting errors. That's most of it.

Feel the manual version first — when the IDE breaks (and it will, usually on
classpath issues), you'll know what layer to look at. See 1.6.

## ⚠️ Traps

- **`java Hello.class` fails.** You pass the *class name*, not the file: `java Hello`.
- **File name must match the public class name.** `public class Hello` must live in
  `Hello.java`. This is enforced by the compiler.
- **Compact source files need Java 25.** On 17 or 21 you still need the full ceremony.

| Thing | Status |

## Recap

| Goal | Command |
|---|---|
| Explore an idea | `jshell` |
| Run one file | `java hello.java` |
| See the two real steps | `javac Hello.java` then `java Hello` |
| See the bytecode | `javap -c Hello.class` |
