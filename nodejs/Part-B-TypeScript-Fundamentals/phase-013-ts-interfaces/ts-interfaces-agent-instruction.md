# Phase 013: Interfaces & Type Aliases
## Agent Instructions

**Phase**: 013 | **Part**: B - TypeScript Fundamentals | **Language**: TypeScript

## Topics
1. Object type annotations: `{ name: string, age: number }`
2. Interfaces: `interface User { name: string }`
3. Type aliases: `type User = { name: string }`
4. Optional properties: `name?: string`
5. Readonly properties: `readonly id: number`
6. Interface vs Type alias — when to use each
7. Extending interfaces: `interface Admin extends User`
8. Intersection types: `type Admin = User & { role: string }`
