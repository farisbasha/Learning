# Phase 012: TypeScript Basic Types
## Agent Instructions

**Phase**: 012 | **Part**: B - TypeScript Fundamentals | **Language**: TypeScript

## Topics
1. Type annotations: `let x: type`
2. Primitive types: `string`, `number`, `boolean`
3. Arrays: `string[]`, `Array<number>`
4. Tuples: `[string, number]`
5. `any` — escape hatch (avoid!)
6. `unknown` — safer any
7. `void`, `never`, `undefined`, `null`
8. Type inference — TS guesses types

## PHP Comparison
| PHP | TypeScript |
|-----|------------|
| `string` | `string` |
| `int`, `float` | `number` (single type) |
| `array` | `type[]` or `Array<type>` |
| `mixed` | `any` or `unknown` |
