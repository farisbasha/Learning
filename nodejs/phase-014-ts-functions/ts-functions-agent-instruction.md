# Phase 014: Functions in TypeScript
## Agent Instructions

**Phase**: 014 | **Part**: B - TypeScript Fundamentals | **Language**: TypeScript

## Topics
1. Parameter types: `function greet(name: string)`
2. Return types: `function add(a: number, b: number): number`
3. Optional parameters: `function greet(name?: string)`
4. Default parameters: `function greet(name: string = "Guest")`
5. Rest parameters: `function sum(...nums: number[])`
6. Function type expressions: `type MathFn = (a: number, b: number) => number`
7. Call signatures in interfaces
8. Function overloads

## PHP Comparison
| PHP | TypeScript |
|-----|------------|
| `function foo(string $s): int` | `function foo(s: string): number` |
| `$param = "default"` | `param: string = "default"` |
