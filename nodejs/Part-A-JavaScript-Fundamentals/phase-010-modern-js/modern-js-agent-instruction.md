# Phase 010: Modern JavaScript Features (ES6+)
## Agent Instructions

## Topics
1. Template literals: `` `Hello ${name}` ``
2. Destructuring: `const { name } = obj` / `const [a, b] = arr`
3. Spread operator: `{ ...obj }` / `[...arr]`
4. Rest parameters: `(...args) => {}`
5. Optional chaining: `obj?.prop?.value`
6. Nullish coalescing: `value ?? defaultValue`
7. `for...of` vs `for...in`
8. Short-circuit evaluation
